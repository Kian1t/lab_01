# toolkit

Консольная программа на Python: калькулятор и конвертер единиц.

## Функционал

**Калькулятор** считает выражения с `+`, `-`, `*`, `/`. Учитывает приоритет операций, дробные числа и минусы перед числом (`-5`, `--5`)

**Конвертер** переводит:
- длину: `mm`, `cm`, `m`, `km`
- массу: `g`, `kg`
- температуру: `c`, `f`, `k`

При ошибке (деление на ноль, неверный символ, неизвестная единица и т.п.) программа пишет сообщение и завершается с кодом `2`

## Как запустить

Нужен Python 3.10+

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e .
```

```bash
python -m toolkit --help
```

Примеры:

```bash
python -m toolkit calc "2 + 3 * 4"
# 14.0

python -m toolkit convert 100 --from g --to kg
# 0.1
```

Тесты:

```bash
pip install pytest
pytest
```

## Алгоритм

**Калькулятор** работает в три шага:
1. Строка разбивается на числа и знаки (tokenization)
2. Проверяется, что числа и знаки идут по очереди: число, знак, число и так далее (validation)
3. Выражение делится на слагаемые по `+` и `-`. Внутри каждого слагаемого сразу выполняются `*` и `/`, потом все слагаемые складываются (calculation).
   Например: `2 + 3 * 4` → `2` и `12` → `14`.

**Конвертер** сначала переводит значение в базовую единицу (метры, граммы или Кельвины), а потом из неё в нужную

## Киллер фичи aka интересные алгоритмы (интересные по версии автора:) )

1. Унарный `-` у числа - рассчитывается через multiplier (каждый унарный минус домножает `multiplier` на -1) и сбрасывается на число (итоговый `multiplier` домножает число)
2. Для выражения рассчитываются умножения и деления, записываются одним числом в новый список чисел в один проход, и потом для этого списка применяется `sum()`, который уже дает результат выражения
3. Для конвертера используется список преобразований через базовую единицу, а не расписана таблица переводов для каждых значений
